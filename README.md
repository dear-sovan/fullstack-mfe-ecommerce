# Enterprise E-Commerce Microservices & Micro-Frontends

Baseline setup featuring Node.js/Express TypeScript backend and React Webpack 5 Module Federation frontends.

## Quick Start
1. Run \`npm run install:all\`
2. Terminal 1: \`npm run start:backend\` (Port 4001)
3. Terminal 2: \`npm run start:mfe\` (Port 3001)
4. Terminal 3: \`npm run start:container\` (Port 3000)
